# Learning the Decoder When to Stop

Length-aware Sanskrit machine translation: a **Target-Length Conditioning
(TLC)** mechanism that tells the decoder, via a length-bucket signal, roughly
how long the output should be, paired with a differentiable length-aware loss
term. Evaluated on Sanskrit→Hindi, Sanskrit→Gujarati, and Sanskrit→Marathi,
across NLLB-200-distilled-600M and mBART-50-many-to-many, with ablations
against RoPE and ALiBi positional-bias variants and a battery of classical
seq2seq baselines (mT5, Transformer-6/12/18, Mamba).

This repository contains **code and datasets only** — no model checkpoints,
logs, SLURM job scripts, or precomputed result tables/figures. Every result
in the paper is reproducible by re-running the scripts below against the
included data.

## Factorial convention

Experiment configs are named `X-ABCD`, a 4-bit switch encoding:

```
A = BBS (bucket-balanced sampling)
B = TLC (target-length conditioning + length-aware loss)
C = RoPE (rotary positional embeddings)
D = ALiBi (attention with linear biases)
```

e.g. `X-0100` = TLC only, `X-0010` = RoPE only, `X-1111` = all four combined.

## Layout

```
data/
  v2/           main Sanskrit-Hindi corpus (train/val/test, .sa + .hi)
  v1/           older/smaller Sanskrit-Hindi corpus, used only by the V1+alpha*V2 scale ablation
  news_test/    out-of-domain news evaluation set, shared Sanskrit source
                translated against Hindi/Gujarati/Marathi references
  indic_data/
    san-guj/    Sanskrit-Gujarati train/val/test splits + split_manifest.json
    san-mar/    Sanskrit-Marathi train/val/test splits + split_manifest.json

configs/
  datasets/{v1,v2}.yaml                dataset fingerprints (generated by scripts/prepare_dataset.py)
  models/{nllb,mbart50_many_to_many,mt5_base,tf6,tf12,tf18,indictrans2_indic_indic_1b}.yaml
  experiments/*.yaml                   per-experiment-group configs (factorial, bbs_grid, tlc_lambda, ...)

src/
  config.py          YAML -> RunConfig, the single source of truth for a run
  data/               bucket assignment, SaHiDataset, manifest/fingerprinting, v1+v2 composition
  models/             model builder (NLLB/mBART/mT5/Transformer/Mamba/IndicTrans2), RoPE + ALiBi,
                       differentiable length-aware loss, bucket-aware embedding
  training/           TALLIPTrainer (seeded BBS sampler, TLC loss term, training-history dump)
  evaluation/          unified generation, BLEU/chrF2/TER/METEOR/BERTScore/COMET + length metrics,
                       per-bucket breakdown, checkpoint loading
  experiments/         run status tracking, failure handling, manifest writing, train_run entrypoint
  statistics/          3-seed aggregation, bootstrap significance (paired, Holm-Bonferroni),
                       factorial (2^4 OLS) interaction analysis
  visualization/       heatmaps, plots, shared style
  reporting/           LaTeX table generation

scripts/              entrypoints for every experiment, ablation, baseline, and analysis
                       (run_factorial, run_mbart50, run_tlc_ablation, train_mamba_baseline,
                       evaluate_news_test*, bootstrap_significance*, factorial_interaction_analysis,
                       generate_figures/tables, prepare_dataset, build_human_eval_template, ...)

tests/                unit tests for buckets, config/cases, length loss, seeding, v1/v2 composition,
                       mBART/manifest handling, bucket-repeat, BBS, stats/viz

requirements.txt      pinned dependency versions (kept for recomputation, not a project doc)
```

A completed run writes to `experiments/<dataset>/<group>/<X-ABCD>/seed_<n>/`
(config, manifest, status, checkpoints, per-split evaluation + metrics) and
`results/{csv,json,tables,figures}/` — neither is included here since this
repo is code + data only; re-running the scripts below regenerates both.

## Setup

```bash
conda create -n nmt_tlc python=3.10
conda activate nmt_tlc
pip install -r requirements.txt
```

Verified working set: Python 3.10, CUDA 12.4, torch 2.6, transformers 4.57.

## Quick start

```bash
# 0. build dataset manifests + fingerprints from data/v2 and data/v1
python scripts/prepare_dataset.py --version v2
python scripts/prepare_dataset.py --version v1
python scripts/compare_datasets.py          # structure + bucket + overlap/leakage report

# 1. run the full 16-config x 3-seed factorial for one architecture
python scripts/run_factorial.py --model nllb      --config configs/experiments/factorial.yaml
python scripts/run_mbart50.py   --config configs/experiments/mbart50.yaml

# 2. evaluate on the out-of-domain news test set
python scripts/evaluate_news_test.py --models nllb mbart50

# 3. aggregate + statistical testing
python scripts/factorial_interaction_analysis.py
python scripts/bootstrap_significance_v2.py

# 4. tables and figures
python scripts/generate_tables.py
python scripts/generate_figures.py
```
